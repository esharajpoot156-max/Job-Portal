# Job Portal

This is a full-stack **Job Portal Web Application** made using the **MERN Stack**. The frontend is built with **Vite and React**, while the backend uses **Node.js, Express.js, and MongoDB**.

The website has three main types of users:

* **Job Seeker** – Can search for jobs, apply for jobs, save jobs, and manage their profile.
* **Employer** – Can post jobs, manage their posted jobs, and view applicants.
* **Admin** – Can manage users, jobs, and other activities on the platform.

## Live Website

[Job Portal](https://job-portal-rose-theta.vercel.app/)

## Technologies Used

* React.js
* Vite
* Tailwind CSS
* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* Cloudinary

## Main Features

* User registration and login
* Role based access for Job Seeker, Employer, and Admin
* Search and filter jobs
* Post and manage jobs
* Apply for jobs
* Save jobs
* View and manage applications
* Profile and resume management
* Admin dashboard

## Deployment

* **Frontend:** Vercel
* **Backend:** Render

## Run Locally

To run the project on your computer:

For frontend:

```bash
cd frontend
npm install
npm run dev
```

For backend:

```bash
cd backend
npm install
npm run dev
```

The frontend will normally run at:

```text
http://localhost:5173
```
